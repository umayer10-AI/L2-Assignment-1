
# TypeScript Assignment

This repository contains my TypeScript assignment, including coding exercises and two technical blog posts.

The main purpose of this assignment is to practice TypeScript concepts such as functions, generics, interfaces, tuples, object-oriented programming, and asynchronous operations.

## Coding Exercises

All TypeScript coding solutions are kept in the `solutions.ts` file.

The assignment covers the following topics:

- Basic functions and type annotations
- Union types and type checking
- Generic functions
- Rest parameters and arrays
- Readonly tuples
- Interfaces and object filtering
- Generics with `keyof`
- Classes and inheritance
- Access modifiers
- Promises and asynchronous programming
- Working with objects and arrays

Each function uses explicit parameter and return types. The code follows the required function and class names from the assignment.
